## Default actions (names only)

Known default hotkey actions (2022 source; current-patch status unverified): camera movement (arrow keys as an alternative), zoom, reset view, tactical view, troop movement and selection, full-screen toggle, quick save, Ctrl+number control groups, select all units, select the Ornithopter, select previous or next, pause, game speed up, down and reset (numpad) and hold-to-speed-up, open Research (Developments), Espionage and Landsraad windows, extended interface, toggle landing-pad visibility, switch between military units left or right, battle view (health bars), queued movement, cancel military operations.

## Commands and speed

There is no attack-move command (Oct 2023 guide); attacks on buildings can be shift-queued since 2023-06-22. Game speed steps are 1, 1.2, 1.5 and 2 in the 2023-24 guide, against "up to x3" in a 2022 Russian blog: the sources conflict (EA 2022 versus 2023-24); trust the 2023-24 value for the current patch, unverified.

## Rebinding

Hotkeys are editable in the Options window (v2.2.8.33019 fixed the list scrolling back to the top while rebinding). The Magnifier's default key is P and can be rebound. There are no native ability keybinds: a modder says players have requested key-triggered hero and ability activation "since launch", and the unofficial patcher adds ability keybinds to the Options menu.
